# astrbot_plugin_space_break

出口空格断句。Grok 写中文常把整句黏死，人设里写「逗号改空格」它只会删逗号。本插件在真正发出前处理 Plain 文本，不靠模型自觉。

## 做什么

- `， , 、 ； ;` 改成空格
- `。 .` 删掉，后面若接汉字则补空格
- 语气词后断开：呀/啊/哦/呢/吧/吗/嘛/啦/懂/了 …
- 话题主语「你/我/他」前断开（「让我」「给我」不切）
- 连续汉字超过 `max_run`（默认 12）硬切
- 链接、CQ 码不切开
- 已经有空格的句子不会再切碎

例：

- `偷看我呀额度还没懂细说下` → `偷看我呀 额度还没懂 细说下`
- `啥额度没懂你说细一点我听听` → `啥额度没懂 你说细一点 我听听`
- `想你了，过来让我靠会。` → `想你了 过来让我靠会`

## 安装

AstrBot 插件页上传 zip，或丢进 `data/plugins/` 后重载。

## 配置

- `enabled` 默认开
- `max_run` 默认 12
- `replace_punct` 默认开
- `particle_break` 默认开

必须重载插件才能装上 send / Context.send_message 补丁。
